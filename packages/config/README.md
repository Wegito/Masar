# @masar/config

Gemeinsame Werkzeug-Konfiguration für alle Workspaces.

- `@masar/config/eslint`: ESLint-Basis (`base({ tsconfigRootDir })`), typbewusst für TypeScript
- `@masar/config/prettier`: Prettier-Konfiguration, im Root-`package.json` eingebunden

Die TypeScript-Basis liegt im Repo-Wurzelverzeichnis (`tsconfig.base.json`).
